# BlackLine Auto

BlackLine Auto est un site de concessionnaire automobile en ligne conçu en HTML et CSS. Il présente une agence moderne avec une navigation simple, un univers visuel noir et élégant, et une sélection de véhicules premium.

## Pages principales

- `index.html` : page d'accueil avec une bannière de présentation, un slogan, et les dernières arrivées.
- `vehicules.html` : page dédiée aux véhicules proposés.
- `style.css` : styles visuels du site, charte sombre et responsive.
- `script.js` : fichier JavaScript actuellement vide, prévu pour de futures interactions.
- `images/` : dossier contenant les visuels des véhicules et le logo.

## Fonctionnalités

- Navigation principale : Accueil, Véhicules, Sportives, Électriques, Services, Contact.
- Liens de connexion et d'inscription dans l'en-tête.
- Section "Nos arrivées du mois" avec cartes de véhicules.
- Effets au survol et style premium sur fond noir.

## Utilisation

1. Ouvrez `index.html` dans un navigateur web.
2. Utilisez le menu pour naviguer vers les autres pages.
3. Pour un rendu local rapide, ouvrez le projet dans Visual Studio Code et utilisez Live Server.

## Structure du projet

- `index.html`
- `vehicules.html`
- `style.css`
- `script.js`
- `README.md`
